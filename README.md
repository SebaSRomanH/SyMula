# SyMula

Visualizaciones simples de conceptos de física. El objetivo es que ver un fenómeno, como la gravitación, haga más fácil aprenderlo y entenderlo. Los simuladores corren en el navegador, sin instalación ni dependencias.

Una idea de Sebastián Román, potenciada por Claude.

**Ábrelo aquí:** https://sebasromanh.github.io/SyMula/

## La idea

La física se entiende mejor cuando se puede tocar. En SyMula no hay que leer primero: se mueve un planeta, se lanza una pelota o se agita el agua, y se mira qué pasa. Las preguntas llegan solas.

- **Para todas las edades.** Cada simulador tiene un botón "Saber más" con una explicación para niños, y al dejar el mouse o el dedo sobre un control aparece qué significa.
- **Física de verdad.** Detrás de cada dibujo hay ecuaciones reales, comprobadas con pruebas contra la teoría.
- **Pensado para el celular.** Funciona en cualquier navegador, mejor en vertical.
- **Abierto.** Cada simulador es un solo archivo que se puede leer y cambiar, y tiene una ficha en PDF con sus fórmulas.

## Los simuladores

| Simulador | Qué puedes hacer |
|---|---|
| Planetas y gravedad | Crear planetas, lanzarlos y descubrir las tres leyes de Kepler, hasta con agujeros negros. |
| Sonido en una sala | Mover un parlante y un oyente, y ver dónde el sonido se hace fuerte o se apaga. |
| Flujo en un tubo | Poner formas dentro de un tubo y ver cómo el agua, el aire o la miel las rodean. |
| Flujo táctil | Agitar una piscina con el dedo y crear ondas y remolinos. |
| Lanzamiento vertical | Lanzar una pelota en la Tierra, la Luna, Marte o Júpiter y medir cuánto sube. |
| Bola de agua | Mover una luna alrededor de una bola de agua y ver cómo levanta las mareas. |
| Fractales | Acercarse sin fin a los conjuntos de Mandelbrot y de Julia. |
| Figuras de Lissajous | Dibujar figuras con dos notas, una en cada oído. |
| Radio AM y FM | Enviar un mensaje de 2 segundos por radio y comparar cómo llega con ruido. |
